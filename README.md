# Industrial DevOps Lab

A hands-on industrial automation and DevOps laboratory
built around Raspberry Pi 5, VMware ESXi on Arm Fling,
Linux virtual machines and industrial control equipment.

## Project Overview

This project combines industrial automation, networking,
virtualization, Linux system administration and infrastructure
monitoring in a single laboratory environment.

## Infrastructure Components

- Raspberry Pi 5
- VMware ESXi on Arm Fling
- Linux virtual machines
- PLC controller
- HMI operator panel
- Industrial Ethernet switch
- Power supply and electrical protection
- Network infrastructure and monitoring
